# 对话工作记忆：原文窗口与thread投影

群聊默认启用[会话解析业务层](dialogue-threads.md)，非活跃消息只存原文与解析状态，活跃消息短聚批分类；回复使用当前thread最近12条加必要旧原文，旁听单独标注。下文的全群80条注入描述适用于 `THREAD_ENABLED=false` 的兼容路径；私聊继续使用80条原文。归属持久化，不随窗口滑动删除；`WORKING_MEMORY_ENABLED=false` 不会绕过已开启的thread隔离，需要同时关闭 `THREAD_ENABLED` 才回退旧群历史。

工作记忆是按群/私聊隔离的近期结构化聊天窗口，不是LLM摘要，也不是单次Agent的推理/工具消息链。长期记忆继续使用新版SQLite权威存储、Qdrant/FTS混合检索、独立提取模型和整合队列。

## 原文窗口

1. 群友互聊（无需唤醒）、用户私聊、确认发送的机器人回复入库后通知`WorkingMemoryManager.receive`，不调用摘要模型。提前分流且未写入聊天库的管理命令不进入。
2. 每次回复从SQLite读取当前批次之前最近`CONTEXT_MESSAGE_LIMIT=80`条有效原文；被遗忘阻断的记录分页排除并补足。当前批次单独放在`当前任务`，后到消息不能提前注入，也不能挤掉本轮历史。
3. 结果放在`背景资料.短期记忆.近期往返`，按原始顺序排列；保留作者QQ/昵称、角色、时间、@目标、寻址、引用和图片资料。机器人真实回复有身份说明。没有`语境摘要`字段。
4. 当前请求明确引用的同群旧消息可额外展开最多4层祖先，因此有引用时总候选可以超过80。原文只出现一次，引用使用消息号/来源ID连接；未加载或不可用的原文明确标注未知，不捏造引用内容。
5. 图片概要/编号附在原消息的`图片资料（非原话）`，不当成发图人的原话；私聊同样支持。图片目录、看图和收藏仍遵守同会话、过期、可用状态和审核限制。

## 预算与原文完整性

短期字符预算取`CONTEXT_MAX_CHARS`与`WORKING_MEMORY_CONTEXT_MAX_CHARS`较小者，默认均24000。80条是候选窗口，不是无限长度保证。

预算足够时保留窗口全部原文，不预先截为1000字。预算不足时优先明确引用和最近8条往返，再优先与当前查询有词面关联的记录；回复与其已加载引用目标作为一个单元选择。长消息必要时保留前缀并标记`原文已截断`；图片概要过大时保留资源编号/状态并标记`图片资料已缩略`。最终JSON包含元数据一起计算预算。

工作记忆使用原文窗口，不调用短期摘要模型。聊天输入token受原文长度和预算影响，总费用仍需实测。

## 生命周期与隔离

- `finish/wait_for_messages`、Agent报错或取消不删除对话记录；下一次仍从相应会话恢复窗口。
- 正群号和负私聊QQ隔离。每次查询重新核对来源存在性和遗忘阻断；历史只是背景，不能成为本轮新授权。
- TTL默认30分钟，**只控制内存缓存空闲淘汰**，不隐藏低频群数小时前仍在数据库中的最近聊天。原文可见期限遵循原有SQLite聊天保留/清理策略；不恢复已删除来源。
- 内存默认最多64会话、每会话128条登记，缓存不足或重启不影响SQLite原文窗口恢复。当前仍只支持单实例/单进程。
- 源记录ID、任务编号、查询缓存由`TaskEvidence`维护；本轮CoT/tool_calls/工具回执仍在Agent局部状态，不进入工作记忆。

## 长期整合不回退

本轮结束仍将真实新用户消息和已成功发出的机器人回复提交原有持久整合队列。未唤醒Agent的普通消息继续以默认30秒/40条增量提取；空闲缓存淘汰及显式整合也可提交真实来源。

当前thread回查使用`read_thread_history`，私聊和关闭thread时自动注入原文。`memory_search`提供`all/event/abstract/perceptual`、人物/时间过滤和来源摘录。`memory_consolidate()`提交边界内最近窗口的真实来源，不清空短期对话。整合流程包含游标/任务归属去重、分批、权限、版本、遗忘阻断、事件/抽象/图片分层和索引同步，不把旧检索或模型草稿当新证据。关闭自动长期提取时，原文上下文仍可独立工作。

## 配置

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| CONTEXT_MESSAGE_LIMIT | 80 | 群/私聊近期原文条数（不含当前批次） |
| CONTEXT_MAX_CHARS | 24000 | 短期原文预算总上限 |
| WORKING_MEMORY_ENABLED | true | 启用原文窗口；false回退旧历史组装 |
| WORKING_MEMORY_CONTEXT_MAX_CHARS | 24000 | 独立短期预算，与总上限取较小值 |
| WORKING_MEMORY_TTL_SECONDS | 1800 | 内存会话空闲淘汰时间，不是来源期限 |
| WORKING_MEMORY_MAX_SCOPES | 64 | 内存会话数上限 |
| WORKING_MEMORY_MAX_MESSAGES | 128 | 单会话增量缓存上限，不限制数据库窗口恢复 |
| CONTEXT_BOT_REPLY_LIMIT | 12 | 仅旧历史回退额外补充机器人发言 |

## 验证

现有测试覆盖原文窗口、批次边界、引用/图片、预算、重启、遗忘与长期记忆操作；部分工作记忆集成测试与当前thread行为不一致，全量测试尚未全部通过。新行为验证按项目约定在仓库外临时执行，不新增回归测试文件。聊天质量和总token开销仍需实际对话评估。
