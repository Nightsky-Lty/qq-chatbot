# 角色卡来源与加载

当前角色卡采用 [shirachino/astrbot-persona-prompts](https://github.com/shirachino/astrbot-persona-prompts) 的 DeepSeek 群友版本，内容适配在 `app/prompts/persona.txt`，由 `app/persona.py` 以UTF-8读取。`PERSONA_PROMPT`与`SYSTEM_PROMPT`为同一份完整文本，群聊、私聊和锐评每次固定注入；专用模仿使用自己的提示词。修改角色卡后重建bot容器生效。

来源为 `deepseek/大肥鱼群友提示词 Beta.docx`，固定于提交 `869d6793b93a756a410f00da44852f8b774e48f1`。作者README说明可按需填写游戏和爱好，角色卡及仓库声明以作者发布内容为准。此为社区二创形象，不代表官方角色设定。

原卡部分仅替换游戏偏好：喜欢原神和英雄联盟（LOL），讨厌鸣潮、王者荣耀和瓦罗兰特，对其他游戏无感，保留原文40%的游戏爱好权重。其余身份表述、性格、反串与回怼方式、口头禅、其他爱好及权重、锐评要求和7组对话示例均按原文保留。DOCX按段落顺序提取为纯文本，不保留Word排版。

角色卡另附7段人工精选的真人群聊，覆盖熟人互损、反问、反话与短句回怼。发言昵称匿名化，并标明每段参考哪位群友；正文保留口语与粗口，仅将具体昵称改为泛称。示例静态保存在同一角色卡中，不自动采样或动态检索，不作为当前请求、共同记忆或角色真实经历，也不改变固定身份与游戏喜好。

功能适配放在角色卡之外：发送字数、分条、网址/代码例外、工具检索与调用、会话隔离、真实回执及群聊/私聊参与规则由 `app/prompting.py` 及实际执行器统一负责；原文提到搜索时使用本项目实际注册的检索工具。角色卡不授予额外工具或访问权限，示例不作为真实聊天历史或操作回执。
