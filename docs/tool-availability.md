# 群聊与私聊工具

通用能力在群聊和私聊共用执行器、检索入口及预算，不依赖模型自行猜测是否支持。工具实际注册取决于功能开关、传输接口和已授权附件；检索仅加载本轮注册的工具，不能获得其他会话权限。角色卡和群聊/私聊交互规则按场景组装。

| 能力 | 群聊 | 私聊 |
| --- | --- | --- |
| 发文字、结束、检索工具 | 支持 | 支持 |
| 联网搜索、读取授权网页 | 支持 | 支持 |
| 更早原文翻页 | 仅当前群 | 仅当前用户与机器人 |
| 六个长期记忆工具 | 本群授权范围 | 当前用户独立记忆 |
| 聊天图片查看 | 本轮授权同群图片 | 本轮授权本人图片 |
| 表情搜索、列表、看原图、发送 | 支持 | 支持 |
| 图片收藏 `collect_sticker` | 当前/近期或检索授权的同群图片 | 用户明确要求时，当前/近期或检索授权的本人图片 |
| 戳一戳 | 本轮允许成员 | 当前聊天用户 |
| QQ AI语音、音色查询 | 群接口支持时注册 | 当前实现使用需群号的NapCat群语音接口，不注册 |
| `wait_for_messages` | 维持群活跃跟进 | 用户新消息直接触发，无此群活跃工具 |
| 创建、查看、取消提醒 | 不注册 | 当前用户提醒 |

普通配置下开启全部通用能力且传输可用时，两种场景共用19个工具；到达表情轮数时，两者还可提供延后表情工具。私聊不开放群管理命令、其他用户的记忆/图片或任意收件人参数。

## 图片收藏

私聊可以发图并要求“存一下这张表情包”，或要求保存刚才已缓存的本人图片。`collect_sticker`使用真实的`media_*`或`image_*`编号；没有候选时不能猜编号、任意下载网址或保存本地路径。关闭聊天看原图不影响独立收藏审核；关闭缓存时仅提供当前消息最多3张候选。

群聊与私聊共用SHA-256去重、视觉审核、原子落盘、容量限制和成功确认。每轮最多尝试一张；重复、拒绝、冷却、来源失效或失败不声称新收藏成功。审核冷却按正群号/负私聊QQ命名空间隔离。私聊不进入随机收图队列，也不另发后台成功播报。

收藏目标是共享表情库，审核通过的图片可在群聊及其他私聊复用；缓存本身仍按来源会话隔离。普通照片、自拍、隐私截图和其他未通过审核的内容不入库。授权缓存引用必须匹配来源命名空间，来源删除、遗忘或过期后不能继续收藏。
