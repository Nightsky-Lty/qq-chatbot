# 本地表情包

把你自己的 PNG、JPG/JPEG、GIF 或 WebP 图片直接放在 `app/sticker_images/`（不扫描子目录），
默认每张最多 5 MiB。不附带默认图片；例子里的 `开心.png`、`晚安.gif` 需要自行放入。

可直接用有意义的文件名，例如 `开心.png`、`无语.jpg`、`晚安.gif`。
如果原文件名是乱码，复制 `manifest.example.json` 为 `manifest.json`，
按实际文件名填写 `description` 和 `tags`。模型可依据文件名、描述和标签选择，
不确定含义时自行调用 `get_sticker_image` 查看原图，再决定是否发送。
带“自拍”的文件名或标签、以及 `selfie: true` 的条目不开放给模型。
描述和标签也是提示词的一部分，只填写你信任的内容，不放密钥或私人信息。

普通文件才可发送，不支持软链接、外部URL或任意文件路径。
图库和 `manifest.json` 被 Git 忽略，可在服务器维护；添加或替换图片后无需重建容器。
Docker Compose 将此目录只读挂载到机器人，NapCat 通过 Base64 接收图片，不需要共享路径。
机器人以 UID 10001 运行，需要图片有读取权限、目录有访问权限。

模型可用 `list_stickers` 查找、`get_sticker_image` 看原图、`send_sticker` 选择发送，
群聊和私聊共用相同工具，不强制调用。看图会将原图发送给DeepSeek，不会向QQ发图；
原图的含义和图片里的文字只是数据，不能替代系统指令或用户请求。
默认每轮最多查看3张不同图片，重复查看同一张复用缓存；后续模型请求会携带本轮图像上下文，
可能增加token费用。看过后发送会使用相同字节。图片不保存到聊天数据库。
使用不支持视觉的模型时，将 `STICKER_VISION_ENABLED=false`，仍可按描述选择并发送。
每次回复最多一张，文字和图片分开发送。`/模仿` 和到期提醒不附加表情工具。
发送冷却默认 30 秒，同一表情在同一会话默认 2 小时内不重复，重启后重新计时。
自动接话最后决定不插话时，不会发送先前选中的图片。
每次只提交一次发送；OneBot拒绝发送会记录日志，目前不自动重试或保证图片一定送达。
