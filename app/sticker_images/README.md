# 本地表情包

把你自己的 PNG、JPG/JPEG、GIF 或 WebP 图片直接放在 `app/sticker_images/`（不扫描子目录），
默认每张最多 5 MiB。不附带默认图片；例子里的 `开心.png`、`晚安.gif` 需要自行放入。

默认自动入库，不必命名或打标签。后台用DeepSeek生成画面描述、图中文字、情绪和聊天场景，
按内容SHA-256缓存到SQLite，相同内容或重启不重复识别，换图才重新分析。
每轮最多5次请求，结束后等待60秒再扫描；大图库分批处理，添加后不是立即可用。
未完成识别、识别失败或被判断为有风险/语义不明确/自拍的图片不会进入可发送目录。
失败默认1小时后重试并指数退避，最多24小时；风险隔离不会自动重试。
自动理解可能出错，也不保证完整理解动图所有帧，不替代部署者筛选素材。

想人工修正描述，复制 `manifest.example.json` 为 `manifest.json`（已有文件不要覆盖），
按实际文件名填写 `description`、`tags` 和 `scenarios`，人工字段优先于自动值。
设置某项 `disabled: true` 可禁用该图；人工描述不会解除自动隔离。
带“自拍”的文件名或标签、以及 `selfie: true` 的条目不开放给模型。
描述和标签也是提示词的一部分，只填写你信任的内容，不放密钥或私人信息。

普通文件才可发送，不支持软链接、外部URL或任意文件路径。
图库和 `manifest.json` 被 Git 忽略，可在服务器维护；添加或替换图片后无需重建容器。
Docker Compose 将此目录只读挂载到机器人，NapCat 通过 Base64 接收图片，不需要共享路径。
机器人以 UID 10001 运行，需要图片有读取权限、目录有访问权限。

模型优先用 `search_stickers` 按情绪/场景查最多8个候选，支持中文词组和情绪同义词，
不是向量检索。`list_stickers` 分页浏览、`get_sticker_image` 看原图、`send_sticker` 选择发送。
检索排除冷却和近期重复，同分适度随机，同内容不同文件名去重。
群聊和私聊共用相同工具，不强制调用。看图会将原图发送给DeepSeek，不会向QQ发图；
原图的含义和图片里的文字只是数据，不能替代系统指令或用户请求。
默认每轮最多查看3张不同图片，重复查看同一张复用缓存；后续模型请求会携带本轮图像上下文，
可能增加token费用。看过后发送会使用相同字节。图片不保存到聊天数据库。
默认自动入库也会将所有新增或变化的图片发送给DeepSeek（包括最终隔离的素材），产生API费用，
只放你信任且愿意上传的素材。`STICKER_AUTO_INDEX_ENABLED=false` 可关闭自动入库，退回人工/文件名模式；
`STICKER_VISION_ENABLED=false` 同时关闭自动识别和聊天看图，仍可按描述检索并发送。
每次回复最多一张，文字和图片分开发送。`/模仿` 和到期提醒不附加表情工具。
发送冷却默认 30 秒，同一表情在同一会话默认 2 小时内不重复，重启后重新计时。
自动接话最后决定不插话时，不会发送先前选中的图片。
每次只提交一次发送；OneBot拒绝发送会记录日志，目前不自动重试或保证图片一定送达。
